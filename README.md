# COMPUTER SECURITY Project

##  Project Overview
This project demonstrates image encryption and decryption using an LFSR (Linear Feedback Shift Register) algorithm with Confusion and Diffusion techniques.

##  Objective
- Encrypt an image (Lena) using LFSR-based key stream
- Apply Confusion using XOR operation
- Apply Diffusion to increase security
- Decrypt the image back to its original form

##  Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

##  Algorithm Used
- LFSR (Linear Feedback Shift Register)
- Confusion (XOR encryption)
- Diffusion (pixel dependency transformation)

##  Result
The system successfully encrypts and decrypts the image with minimal loss, demonstrating basic principles of symmetric image encryption.
